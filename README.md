# BYOK Store (Android)

A native storefront for the BYOK app catalog: browse 115+ (and growing) bring‑your‑own‑key AI apps, search by tool or category, and install with one tap (downloads the signed APK from GitHub Releases and hands it to the package installer).

- Catalog source: https://mohithash.github.io/byok-store/catalog.json (regenerated from the factory specs)
- Web version: https://mohithash.github.io/byok-store/
- Icons are drawn from the same glyph + palette data the launcher icons use, so they match exactly.

Jetpack Compose · Material 3 Expressive · DownloadManager + FileProvider. `./gradlew :app:assembleRelease`
